How To Guide

A simple walkthrough of how the app works.

Create projects

Use New Project to add a project name and description, then create the project card.

Manage the work

Open a project card to add tasks, paste task lists, write notes, set priority, add tags, and invite collaborators. If you already share projects with people, use the Invite someone dropdown to pick them quickly.

Organize your view

Use Active, Shared, and Completed to switch sections. Search and Sort help narrow down the project cards.

Track progress

Use the leaderboard modes to switch between Weekly, Monthly, and All Time rankings. Personal achievements and Level Up awards appear as you earn XP.

Save and recover

Changes save automatically when the status says All changes saved. Use More... for archived projects, undo, shortcuts, and this guide.
